# Dataset Documentation & Data Privacy Guide

## Overview

This repository provides an automated data quality and governance analysis pipeline for audio transcription crowdsourcing platforms. 

In compliance with data privacy, intellectual property, and confidentiality standards, **the raw audio transcription dataset is not tracked in version control**.

## Dataset Placement

To reproduce the analysis locally:
1. Obtain the internal evaluation export `transcription_data.csv` from authorized project storage.
2. Place the file in the `data/raw/` folder:
   ```text
   data/raw/transcription_data.csv
   ```

## Dataset Specifications & Verified Schema

- **Total Records:** 51,783 task submissions
- **Unique Transcribers:** 48,875 user accounts
- **File Format:** UTF-8 encoded CSV

| Column Name | Data Type | Description |
|:---|:---|:---|
| `user_id` | `int64` | Unique numeric identifier for each transcriber account. |
| `recording_url` | `str` | Cloud storage URI to the segmented audio file (.mp3). |
| `whisper_text` | `str` | Pre-populated reference transcription generated by OpenAI Whisper. |
| `user_text` | `str` | Final transcript submitted by the transcriber (may contain `[blank]`). |
| `is_edited` | `str` | Flag indicating whether user modified the transcript (`Yes` / `No`). |
| `duration` | `float64` | Audio recording duration in seconds. |
| `time_taken_by_user` | `float64` | Elapsed time spent by transcriber on the task screen in seconds. |
| `segment_character_per_second` | `float64` | Platform-recorded characters per second throughput. |

## Data Privacy & Anonymization Safeguards

1. **Confidential Audio Links:** The audio URLs reference internal, private Google Cloud Storage buckets. These URLs are never committed to the public repository.
2. **Personal Identifiable Information (PII):** Transcriber profiles are referenced solely by arbitrary anonymized numerical identifiers (`user_id`). No names, emails, phone numbers, or IP addresses are present or exposed.
3. **Local Preservation:** Executing cleanup scripts or running the analysis pipeline never alters, truncates, or deletes the local `data/raw/transcription_data.csv` master file.
